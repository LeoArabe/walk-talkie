# Walk-Talkie (English Audio Connect)

[Portugues](#portugues) | [English](#english)

---

## Portugues

### Sobre
Aplicativo MVP de chat de audio anonimo em tempo real para pratica de idiomas. Sem texto, sem video - apenas fale e ouca. Conecte-se com pessoas ao redor do mundo para praticar outro idioma de forma natural.

### Tecnologias
- Node.js + Express + Prisma
- PostgreSQL
- WebRTC + Socket.IO
- React Native + Expo
- Docker + GitHub Actions

### Como rodar
Projeto em desenvolvimento inicial. Instrucoes de setup serao adicionadas conforme o projeto avanca.

### Status
Em desenvolvimento inicial - configuracao do ambiente e estrutura base.
